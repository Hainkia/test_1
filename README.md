# 수업 설계 노트

학년·과목·성취기준을 입력해 Gemini API로 5단계 수업지도안 초안을 만드는 정적 웹앱입니다.

## Vercel 배포

GitHub 저장소를 Vercel에 연결하고 프로젝트 루트는 저장소 루트로 설정하세요. 프레임워크는 `Other`, 빌드 명령은 비워 두면 됩니다. `vercel.json`이 배포 디렉터리로 `dist`를 지정합니다.

Gemini API 키는 각 사용자가 브라우저에서 직접 입력합니다. 키를 저장소, HTML 또는 Vercel 공개 환경 변수에 넣지 마세요. 이 앱은 입력한 키를 브라우저에서 Gemini API로 직접 전송합니다.
